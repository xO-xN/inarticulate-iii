Inarticulate III · 文件系统架构

三位演奏者的网络化数字乐谱 — 触摸经 Socket.IO 汇聚为声音：浏览器页面层（public/）· Node 乐谱服务器（server.js + lib/）· 作品音频层（audio/）· SuperCollider 合成引擎

DATA FLOW

触摸 → 声音主链路

  • 演奏者触摸 sketch.js 发出 point / lineStroke，经 Socket.IO 到达 server.js
  • 服务器转发为 setPlayerGate / setPlayerPosition / setPairStroke 调用 audio/controller.js
  • Internal 模式：audio-engine.js 经 /n_set 直控单合成器节点 1001（三声部互调）
  • External 模式：osc-transport.js 发送作品自有 /p* 协议到任意 OSC 目标

CONTRACT

双端共享契约

  • shared.js 同时被浏览器与 Node require：事件名、玩家 ID、存储 key 只定义一次
  • 端口唯一事实源是 manifest.json，经 __config.js 注入浏览器
  • 玩家认领通过 claim token 支持断线重连与设备接管

RUNTIME BOUNDARY

运行时边界

  • scsynth 由宿主（PNDS App 或终端）拥有，服务器只在其上创建 group 1000 / node 1001
  • .scsyndef 由 .scd 源码编译，运行时只加载编译产物，从不启动 sclang
